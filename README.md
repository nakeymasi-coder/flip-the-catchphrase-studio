# Flip the Catchphrase Studio

A self-contained merchandise text-prompt generator by Glam.

Live studio: https://nakeymasi-coder.github.io/flip-the-catchphrase-studio/

Open **Menu** to choose a saying, scene, character, product, art styles and typography, or start with one of 53 editable presets. **How to use** opens the built-in guide.

Each selected art style produces one separate complete prompt. Copy a prompt, Copy All, or Copy Batch Prompt, then paste the text into an image generator. This tool does not generate images or provide a live TikTok trend feed.

Drafts, saved sayings and favorites remain in your browser. Export or copy a backup before switching devices, moving from the local preview to this website, or clearing browser data. Import supports older Flip the Script backups.

## Files

- `index.html`: the complete application with inline CSS and JavaScript.

The catchphrase library contains archived, source-linked examples. Commercial rights to source material are not granted by this tool. Check rendered text and supplier print templates before production.
